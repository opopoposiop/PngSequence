# Security policy

Please do not include credentials, private media, or other sensitive information in a public issue.

For a suspected security vulnerability, use GitHub's private vulnerability reporting feature if it is enabled for this repository. If it is not available, open a minimal issue asking for a private contact channel without disclosing exploit details.

This project is a local Windows application. It does not upload input images or output videos during normal execution. The build script downloads the pinned FFmpeg archive from BtbN during the build process.
